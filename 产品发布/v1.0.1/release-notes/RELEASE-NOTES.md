# Nomos v1.0.1 发布说明

## 版本信息

- **版本号**：1.0.1
- **发布日期**：2026-06-04
- **版本类型**：首个可用修正版
- **发布渠道**：Windows x64 便携版

## 版本目标

Nomos v1.0.1 是从内部原型到可用产品的首个发布版本。目标：

> 用户能安装 Nomos 桌面客户端，创建项目，检测和配对本地 Agent，通过五阶段工作流派发任务、追踪进度、验收交付物，并完成本地备份恢复。

## 新增能力

### 核心功能

- **Electron 桌面客户端**：Windows x64 便携版，单实例启动，重复打开时聚焦已有窗口
- **本地 HTTP 后端**：Node.js 服务，端口 4174，JSON 文件持久化，无需额外数据库
- **项目管理**：创建、编辑、删除、搜索项目，项目设置保存
- **五阶段交付链路**：提出目标 → 总管拆解 → PRD → 本地开发 → 测试 → 预览发布 → 人工验收
- **总管工作流状态机**：任务信封、阶段回执、交接记录、待验收、失败阻塞、上游返工

### Agent 接入

- **Alice MCP 接入**：任务派发预览、显式确认、审计记录、同轮幂等拦截
- **Claude Code 接入**：本地进程执行、输出解析、结构化回执
- **Codex CLI 接入**：隔离模式执行、输出解析、结构化回执
- **OpenClaw 占位**：检测但保持待配置，不自动初始化
- **统一 Agent 路由**：路由结果包含候选适配器、选择理由、幂等键

### 执行控制

- **受控本地执行**：执行预览、目录授权、只读模式、写入二次确认、取消、重试、超时终止、异常恢复
- **Alice MCP 派发**：预览与显式确认，任务状态与审计日志
- **部署执行**：确认执行项目目录中的 npm script，登记预览 URL

### 数据管理

- **项目资料**：文件说明、URL、阶段绑定、增删管理
- **本地备份恢复**：JSON 备份、恢复预览、恢复前保护快照、活动任务恢复拦截
- **目录授权**：额外授权目录配置与撤销

### UI/UX

- **主界面**：项目总览、阶段链路、协作动态、项目资料、规则与权限、执行详情
- **Agent 列表**：状态展示，实时探测 Alice/Claude Code/Codex CLI
- **首次启动引导**：空工作区创建第一个项目或检查本地 Agent
- **弹窗确认**：所有确认、输入、派发、备份、恢复动作统一为应用内弹窗

## 修复问题（相对内部原型）

- 修复 Electron 桌面壳不支持原生 `prompt()` / `confirm()` 导致按钮无响应的问题
- 新安装默认进入空工作区，不再写入演示项目和资料
- 左侧 Agent 列表改为状态展示，不再伪装成不可点击按钮

## 已知边界

- **OpenClaw**：已检测但保持待配置，不会自动初始化或启动网关
- **多用户协作**：当前版本为本地优先单机 MVP，不支持远程账号和团队协作
- **数据同步**：不支持云端同步，数据仅保存在本地
- **平台支持**：仅支持 Windows x64

## 验证结果

- **自动化测试**：32 项通过（`npm test`）
- **生产源码扫描**：无 `window.prompt` / `window.confirm`，无演示项目文案
- **浏览器烟测**：空工作区、创建项目、提交成果、代码写入、Agent 团队、备份入口等关键按钮均可打开对应弹窗
- **DOCX 操作说明书**：结构检查通过

## 包信息

- **格式**：Windows x64 便携版（.exe）
- **运行时**：内嵌 Electron 42.3.0 + Node.js
- **数据目录**：Electron 用户数据目录（开发模式为项目内 `.local-data`）

## 使用方式

1. 下载便携版可执行文件
2. 首次启动进入引导页
3. 创建项目或检查本地 Agent
4. 按五阶段链路管理项目交付

## 回退方式

- 卸载即回退：删除可执行文件和用户数据目录即可完全清除
- 数据备份：通过应用内备份功能导出 JSON 数据
