# nomos Desktop 1.1.0

## 本次版本

`1.1.0` 是组织管理版，在 `1.0.1` 本地优先 Agent 项目指挥台基础上，补齐 Skill Pool、Role、Employee、Technical Adapter 的组织层模型。

## 新增能力

- 组织管理页面：概览、Skill 池、岗位、员工、数字员工工厂五个子页。
- Skill 池 CRUD：支持名称唯一性、分类、等级、来源、标签、适用流程、风险边界和能力证据字段。
- 岗位 CRUD：支持岗位族、碳/硅/混编类型、职责、Skill 组合、验收标准和流程关联说明。
- 员工 CRUD：支持碳基、硅基、混编员工，硅基员工引用现有本地 Agent。
- Adapter 视图：从现有 `agents` 和 `agentAdapters` 聚合展示技术架构身份。
- 组织健康度：统计 Skill、岗位、员工、Agent 覆盖率、空岗位族、无员工岗位和无 Skill 岗位。
- 默认模板：通过 `POST /api/org/init-defaults` 按需生成 7 大岗位族、21 个 Skill 和 8 个岗位。
- 数字员工工厂前三步：岗位匹配、入职培训、师父带教，支持草稿保存、恢复和状态机校验。
- 数据迁移：`nomos-data.json` 从 v6 升级到 v7，自动补全 `skills`、`roles`、`employees`。

## 保留能力

- Windows x64 便携客户端。
- 本机 HTTP 后端和 JSON 持久化，无需额外数据库。
- 项目创建、编辑、删除、搜索和五阶段交付链路。
- Alice MCP、Claude Code、Codex CLI、本地执行预览、二次确认、取消、重试和回执。
- OpenClaw 保持待配置，不自动初始化或启动网关。
- 本地备份、恢复预览、恢复前保护快照和活动任务恢复拦截。

## 当前边界

- 数字员工工厂仅落地前三步，分配工具、上手实习、转正上岗留到 v2.1。
- 流程管理仍在 v1.2 规划中，v1.1 的岗位流程关联为 `flowNotes` 自由文本。
- 当前版本仍是本地优先单机客户端，尚未接入远程账号、云端同步和团队协作服务。
