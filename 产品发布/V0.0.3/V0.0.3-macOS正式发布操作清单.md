# Nomos V0.0.3 macOS 正式发布操作清单

当前 DMG/ZIP 是通过完整测试和真实启动验证的内部候选包。正式公网发布需在 GitHub Actions 配置 `MAC_CSC_LINK`、`MAC_CSC_KEY_PASSWORD`、`APPLE_ID`、`APPLE_APP_SPECIFIC_PASSWORD`、`APPLE_TEAM_ID`，随后合并发布分支并推送 `v0.0.3` 标签。

流水线会自动完成 Developer ID 签名、Apple 公证、Gatekeeper/stapler 校验、SHA256 生成和 GitHub Release 创建。任一门禁失败都不会发布。
