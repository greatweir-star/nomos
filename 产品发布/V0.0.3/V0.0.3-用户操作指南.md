# Nomos V0.0.3 用户操作指南

## 最短成功路径

1. 在“设置 → 技术连接”检测 Codex、Claude Code、Kimi 或 Alice，测试并保存至少一个可管理连接。
2. 在“能力池”建立 Skill；在“组织”创建岗位，并填写职责、验收标准和所需 Skill。
3. 用岗位和连接创建硅基员工，完成入职检查；同一连接可创建多个会话隔离员工。
4. 在“流程”创建流程草稿，配置节点、岗位、依赖和验收规则；校验通过后发布版本。
5. 在“项目”选择已发布版本启动项目，核对快照版本和生成的工作项。
6. 在“派发”查看候选解释，选择员工并确认；重复确认不会产生第二次执行。
7. 执行方提交结构化回执后，工作项进入待验收；验收人选择通过、驳回或返工。

## 日常维护

- 连接异常时先禁用或重检，异常连接不会进入新派发候选。
- 升级、迁移或大批量操作前创建备份。
- 定期查看“设置 → 安全与审计”，确保原始会话字段与敏感审计命中均为 0。
- 系统异常退出后重新启动，检查控制台异常项和派发状态。
