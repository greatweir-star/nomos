# Nomos v1.3.0 发布说明

本版新增工作项事实账本和进度资源看板，重点解决“阶段下有哪些具体工作、谁负责、依赖是否阻塞、项目和资源进度如何查看”的问题。

## Highlights

- 工作台：新增工作项、进度看板、资源看板。
- 工作项：支持流程阶段项、旧任务镜像项、项目临时项。
- 事件账本：工作项关键变更写入 `workItemEvents[]`。
- 依赖校验：未完成依赖会阻止工作项进入执行中。
- 旧链路兼容：旧 `workflowTasks[]` 自动进入看板统计。
- 数据迁移：`nomos-data.json` 升级到 v9。

## Test

`npm test` 通过 49/49。
