# Nomos v1.3.0 版本说明

## 版本定位

v1.3.0 是“工作项与进度资源看板版”。它承接 v1.2 流程管理，把项目阶段和旧五阶段任务统一沉淀为可分配、可追踪、可审计的工作项，为 v1.4 Agent 派发和 v2.0 Workflow 引擎提供数据地基。

## 新增能力

- 新增数据版本 v9：`workItems[]`、`workItemEvents[]`。
- 新增工作台入口：工作项、进度看板、资源看板三页。
- 支持 `manual`、`flow_stage`、`legacy_workflow_task` 三类工作项来源。
- 支持工作项创建、更新、开始、完成、阻塞、取消。
- 支持负责人、预计工时、截止时间、验收标准、Markdown checklist。
- 支持同项目依赖、自依赖/循环依赖拦截、依赖未完成阻断执行中。
- 支持旧 `workflowTasks[]` 按需镜像进入统一看板。
- 新增进度看板：完成率、工时完成率、阶段进度、阻塞链路、最近事件。
- 新增资源看板：按员工、Agent、岗位、未分配统计负载和剩余工时。

## 新增 API

- `GET|POST /api/work-items`
- `GET|PATCH /api/work-items/:id`
- `POST /api/work-items/:id/cancel`
- `POST /api/work-items/:id/dependencies`
- `DELETE /api/work-items/:id/dependencies/:dependencyId`
- `GET /api/work-items/:id/events`
- `POST /api/work-items/:id/comments`
- `POST /api/work-items/sync-legacy`
- `GET|POST /api/projects/:id/work-items`
- `GET /api/projects/:id/board-summary`
- `GET /api/dashboards/progress`
- `GET /api/dashboards/resources`
