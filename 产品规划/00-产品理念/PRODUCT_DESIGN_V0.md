# Nomos（诺莫斯）—— 企业智能操作系统

> **秩序即智能。**

---

## 一、核心哲学

华为说：能力建在组织上，组织跑在流程上。Nomos 在此基础上再加一条：企业运转透明可控。

Nomos 的三条产品设计理念是：

1. **能力建在组织上**：Skill、知识、经验和工具能力沉淀为组织资产，不随单个人流动而流失。
2. **组织跑在流程上**：流程是组织的骨架，不依赖具体的人，却能承载组织的全部能力。
3. **企业运转透明可控**：项目、流程、员工、智能体、权限、产出、风险和验收都应被实时看见、可追踪、可审计、可干预。

这三条理念的底层逻辑是：**企业不是一堆工具和人员的集合，而是一套可见、可调度、可复盘的秩序系统。**

Nomos 把这个逻辑推进到 AI 时代：**流程不再是僵化的审批链，而是碳基生命（人）与硅基智能（AI Agent）协同运转的秩序系统。**

不是"用 AI 取代人"。人擅长创造、判断、建立关系；AI 擅长记忆、整合、监控、执行。Nomos 的设计核心是**碳硅协同**：在流程的每个节点上，明确谁来做、做到什么标准、输出什么成果。节点可以是人，可以是 Agent，也可以是人借助 Agent 完成。

## 二、产品定位

| 维度 | 定义 |
|------|------|
| **是什么** | 面向中小企业和 OPC 的「流程驱动型智能操作系统」 |
| **不是什么** | 不是全自动的"无人公司"，不是替代人的工具，不是又一个 OA/ERP |
| **服务谁** | 有增长焦虑的中小企业（10-300人）、追求效率的个体创业者（OPC） |
| **解决什么** | 流程靠人脑记、经验随人走、部门各自为政、老板是最大瓶颈 |
| **核心差异** | 把华为级的流程方法论轻量化、智能化、平民化，让中小企业用得起、落得了地 |

## 三、从华为流程提炼的六大设计要素

Nomos 的设计不是凭空创造，而是从华为 16 条一级业务流程的实践中提炼核心要素，重新建模为 AI 时代的流程操作系统。

### 要素一：端到端价值流

华为所有流程都遵循"从客户需求到客户满意"的端到端逻辑。IPD 不是研发部的流程，LTC 不是销售部的流程，它们都是跨部门的完整价值流。

**Nomos 设计**：Workflow 不是部门内的审批链，而是横跨角色的端到端价值流。一条 LTC Workflow 从线索生成开始，经过商机评估、方案设计、报价审批、合同签订、交付跟踪、开票回款，最终到客户满意度回访——全程不因为"这是财务的事"或"这是销售的事"而中断。

### 要素二：三层流程分类

华为把流程分为执行类（直接创造价值）、使能类（为前线赋能）、支撑类（基础设施）。这个分类让资源投入有了优先级。

**Nomos 设计**：Workflow 按三层分类管理：
- **价值流（执行类）**：LTC、IPD、IPMS、ITR——直接面向客户，优先级最高
- **使能流**：MCR、DSTE、Supply——为价值流提供弹药和策略
- **支撑流**：MF、MHR、MQ——保障组织长期稳定运转

### 要素三：分层分级架构

华为流程分 L1（业务域）→ L2（流程组）→ L3（流程）→ L4（子流程）→ L5（活动）→ L6（任务），从战略到执行逐层展开。

**Nomos 设计**：Workflow 支持五级分层：
- **L1 价值流**：端到端的大流程（如"线索到回款"）
- **L2 阶段**：流程中的主要阶段（如"管理线索→管理机会点→管理合同执行→开票回款"）
- **L3 任务**：阶段内的具体任务（如"商机评估"）
- **L4 步骤**：任务的执行步骤（如"收集客户信息→评估预算→判断决策链"）
- **L5 节点**：步骤中的原子操作，标注碳/硅/碳硅属性

### 要素四：碳硅节点类型

华为流程中有明确的角色分工（如 LTC 铁三角：AR 客户经理、SR 方案经理、FR 交付经理）。在 Nomos 中，角色被扩展为"碳硅混合角色"——每个节点明确由人还是 Agent 执行。

**Nomos 设计**：Workflow 中的每个节点有三种类型：

| 节点类型 | 执行者 | 典型场景 | 华为映射 |
|---------|--------|---------|---------|
| **碳节点** | 人 | 战略决策、客户拜访、创意头脑风暴、复杂谈判、关系建立 | 高层决策评审、关键客户接触 |
| **硅节点** | Agent | 数据收集、信息整合、规则校验、监控告警、报告生成、知识检索、日程排期 | 自动化数据采集、SLA 监控、报表生成 |
| **碳硅节点** | Agent 辅助 + 人决策 | 方案推荐（Agent 生成，人选择）、风险评估（Agent 分析，人判断）、合同初筛（Agent 提取关键条款，人终审） | 技术评审（TR）、决策评审（DCP） |

关键原则：**不是所有节点都适合自动化，也不是所有节点都必须人来。流程的设计者（碳）决定每个节点的类型，系统（Nomos）负责调度执行。**

### 要素五：评审与关口机制

华为在 IPD 中设置了 DCP（决策评审点）和 TR（技术评审点），每个关口都有明确的准入标准和准出标准。这是华为流程不跑偏的核心机制。

**Nomos 设计**：Workflow 中设置"关口节点"（Gate），每个关口有：
- **准入条件**：进入此阶段前必须满足的条件（如"商机金额超过 10 万需提交风险评估"）
- **准出标准**：离开此阶段必须达成的标准（如"合同必须经过法务审核且风险评级为低"）
- **评审方式**：可以是碳评审（人开会决策）、硅评审（Agent 自动校验规则）、碳硅评审（Agent 预审 + 人终审）

### 要素六：流程与人员解耦

华为强调"流程不绑定具体的人"。IPD 中的 PDT 团队是一个角色集合，不是固定的几个人。铁三角也是角色定义，人可以换，流程不变。

**Nomos 设计**：
- **Workflow 绑定角色，不绑定人**：一条 LTC Workflow 需要 AR/SR/FR 三个角色，但具体是谁由组织配置决定
- **Skill 沉淀在组织**："怎么评估商机""怎么写 Charter"这些能力以 Skill 形式存在，不因人员流动而消失
- **Agent 继承角色**：当某个角色暂时无人时，Agent 可以顶岗执行硅节点；当人员变动时，新加入的人通过 Agent 快速继承角色的记忆和 Skill

## 五、核心模块

### 5.1 Workflow 引擎

Workflow 引擎是 Nomos 的核心。它不是 BPM（业务流程管理）的翻版，而是专门为碳硅协同设计的流程调度系统。

**五级分层**：
- L1 价值流：端到端的大流程，如"线索到回款"
- L2 阶段：流程的主要阶段，如"管理线索→管理机会点→管理合同→开票回款"
- L3 任务：阶段内的具体任务，如"商机评估"
- L4 步骤：任务的执行步骤，如"收集信息→评估预算→判断决策链"
- L5 节点：原子操作，标注碳/硅/碳硅属性

**碳硅节点调度**：
- 碳节点：系统推送待办到人的工作台，设定截止时间，超时升级
- 硅节点：Agent 自动执行，执行结果回写记忆系统，异常情况转碳节点
- 碳硅节点：Agent 先生成建议/方案/分析报告，人基于输入做决策，决策结果回灌系统

**事件驱动**：市场变化、客户行为、数据异常、时间触发……任何信号都可以启动或推进一条 Workflow。

**示例**：LTC Workflow
> 线索生成（硅：Agent 从多渠道捕获线索并自动去重）→ 线索评分（硅：Agent 按规则打分）→ 线索分配（碳硅：Agent 推荐分配方案，销售主管确认）→ 商机评估（碳硅：Agent 生成客户画像和竞品分析，销售判断可行性）→ 方案设计（碳：销售 + 方案经理协作）→ 报价审批（碳硅：Agent 校验折扣权限，主管审批）→ 合同签订（碳：法务/客户签字）→ 交付跟踪（硅：Agent 监控交付进度，异常告警）→ 开票回款（硅：Agent 按时推送开票提醒，跟踪回款）→ 客户回访（碳：销售主动回访，Agent 记录反馈）

### 5.2 碳硅角色网络

Nomos 中的角色不是"岗位"，而是"流程中的职能定义"。每个角色有明确的职责边界、权限范围、Skill 清单，以及——最关键的——**碳硅属性**。

| 角色类型 | 说明 | 示例 |
|---------|------|------|
| **纯碳角色** | 必须人执行，Agent 仅辅助 | CEO、销售总监、客户经理（客户关系建立） |
| **纯硅角色** | Agent 自主执行，无需人介入 | 数据监控 Agent、报表生成 Agent、知识检索 Agent |
| **碳硅混合角色** | 日常由人执行，Agent 顶岗；或 Agent 辅助人执行 | 销售助理（Agent 做线索初筛，人做深度跟进）、财务审核（Agent 做规则校验，人做异常判断） |

角色的核心属性：
- **Role Profile**：职责、权限、汇报线、KPI
- **Skill Access**：可调用的 Skill 清单
- **Memory**：角色的工作上下文和历史记录
- **State**：忙碌/空闲/异常
- **碳硅配比**：此角色有多少节点是碳、多少是硅

### 5.3 Skill 体系

Skill 是**组织能力的标准化封装**。华为把最佳实践沉淀为流程模板、检查清单、操作手册；Nomos 把这些进一步封装为 Skill——可被 Workflow 调用、可被 Agent 执行、可随使用持续迭代。

Skill 的三种来源：
- **华为方法论轻量化**：把华为级流程（如 LTC 铁三角、IPD 阶段门、IPMS GTM）拆解为中小企业可落地的 Skill
- **组织实践沉淀**：企业内部优秀的操作方式被萃取为标准 Skill
- **通用基础 Skill**：如"生成周报""解析合同条款""客户画像分析"

Skill 的分级：
- **L1 原子 Skill**：单一能力单元
- **L2 复合 Skill**：多个原子 Skill 组合完成一个任务
- **L3 流程 Skill**：面向特定端到端流程的完整能力集（如"LTC 轻量版"）
- **L4 领域 Skill**：面向特定行业的解决方案（如"跨境电商 LTC""SaaS 公司 IPD"）

### 5.4 组织记忆

组织的「外脑」，解决"人走茶凉"和"新人上手慢"的问题。

三层记忆：
- **感知记忆**：当前正在运行的 Workflow 状态、实时数据流
- **工作记忆**：本周期内的关键决策、项目进展、客户动态
- **长期记忆**：
  - 显性知识（流程模板、制度文档、历史决策记录）
  - 隐性知识（通过碳硅交互沉淀下来的"know-how"）
  - 客户关系（客户档案、决策链地图、历史沟通记录）
  - 组织图谱（角色关系、协作模式、信息流向）

**关键设计**：当一位碳角色离职时，其 Agent 的历史交互、决策模式、客户洞察自动归档到组织记忆；新碳角色加入后，通过继承该角色的 Agent 快速获得上下文，而非从零开始。

## 六、碳硅协同：三种典型模式

### 模式一：硅采集，碳决策

Agent 负责收集信息、整理数据、生成分析报告；人基于完整的信息输入做判断和决策。

**场景**：销售主管每天早上打开 Nomos，Agent 已自动生成"昨日线索漏斗""本周商机健康度""高风险回款预警"三张简报。主管花 10 分钟看完，决策"重点跟进哪三个机会""是否需要调配资源支持某项目"，指令回灌系统后 Workflow 自动推进。

### 模式二：碳创造，硅记忆

人负责创意、方案、关系建立；Agent 负责记录、归档、跟进、提醒。

**场景**：销售拜访客户后，口头或随手记录要点，Agent 自动整理为结构化客户档案，更新决策链地图，生成下次拜访建议，并在合适时间提醒跟进。销售只需要专注在"见客户"和"想方案"，其他琐事由硅接手。

### 模式三：硅值守，碳介入

Agent 7×24 小时监控运行状态，按规则自动处理常规事项；只在异常、超限、模糊情境下唤醒人。

**场景**：合同回款 Workflow 中，Agent 监控每笔款项的到账状态。正常到账自动确认、更新财务记录；逾期未到账时，Agent 先自动发送催款提醒，若超期 7 天仍未到账，则升级为碳节点，推送至财务负责人和销售主管的工作台，附带完整的账龄分析和客户沟通建议。

## 七、与传统系统的区别

| 维度 | 传统 OA/ERP/CRM | Nomos |
|------|----------------|-------|
| **视角** | 功能模块（财务模块、销售模块...） | 端到端价值流（从客户需求到客户满意） |
| **流程** | 预设、刚性、人推动 | 动态编排、事件驱动、碳硅混合调度 |
| **角色** | 绑定具体的人或岗位 | 绑定角色定义，碳硅可互换、可继承 |
| **知识** | 文档库，靠人检索 | Skill 化，Workflow 自动调用 |
| **人机关系** | 人使用系统 | 碳硅协同，各做擅长的事 |
| **传承** | 换人=经验归零 | 记忆沉淀，角色可继承 |

## 八、设计原则

1. **端到端优先于局部优化**：Workflow 必须跨部门闭环，不做"部门内最优、公司级次优"的设计
2. **碳硅互补，而非替代**：人做人擅长的，Agent 做 Agent 擅长的，不追求全自动
3. **关口清晰，标准明确**：每个评审点有准入准出标准，不能模棱两可
4. **流程与人员解耦**：Workflow 绑定角色，Skill 沉淀组织，不因人走而凉
5. **轻量化落地**：华为方法论是骨架，中小企业场景是血肉，不做过度设计
6. **闭环优先**：任何信号必须有反馈，任何行动必须有结果回流

## 九、命名说明

**Nomos（诺莫斯）**
- 源自古希腊语 νόμος，意为「秩序、法则、习俗、分配」
- 与 physis（自然本性）相对，nomos 代表人为建立的理性秩序
- 城邦的律法、社会的习俗、资源的分配、运行的规则，皆属 nomos
- 后衍生出 economy（家政/资源配置）、astronomy（天体运行法则）、autonomy（自治/自律）
- 一家企业，本质上就是一套 nomos：人为设计的秩序，让一群人朝同一方向运转
- 两音节，发音干净（/ˈnoʊmɒs/），辨识度高
