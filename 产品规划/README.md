# 产品规划

这里存放 Nomos 产品层面的材料。

- `00-产品理念`：产品定义、设计理念、命名含义、总体架构。
- `01-调研资料`：行业、竞品、流程方法论、需求映射等调研材料。
- `02-PRD`：产品需求文档。
- `03-版本规划`：Roadmap、里程碑、版本范围和优先级。
- `04-详细规划`：面向工程落地的详细设计、数据模型、接口边界和验收标准。

开发任务开始前，应先确认相关规划材料是否已经存在，避免只按局部功能推进。
