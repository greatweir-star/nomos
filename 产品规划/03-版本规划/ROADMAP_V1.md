# Nomos Roadmap V1

> 从 v1.0.1 MVP 到企业级智能操作系统。

---

## 产品愿景

Nomos 要成为面向中小企业和 OPC 的流程驱动型智能操作系统。核心理念：

> 能力建在组织上，组织跑在流程上，企业运转透明可控。

## 北极星指标

> 用户能用 Nomos 把一个端到端流程交给"人 + Agent + Workflow"协同运行，并稳定得到可追踪、可验收、可复盘的结果。

---

## 版本总览

```
v1.x 基础设施 ──→ v2.x 协同引擎 ──→ v3.x 生态智能
(MVP → 可用)     (可用 → 有用)       (有用 → 离不开)
```

---

## v1.x 基础设施阶段

**目标**：让 Nomos 从"能跑的 MVP"变成"有组织、有流程、可管理"的产品基础。

### v1.0.1 已完成

- Electron Windows x64 便携客户端
- 单实例启动、本机 HTTP 后端、JSON 持久化
- 五阶段交付链路（提出目标 → 总管拆解 → PRD → 本地开发 → 测试 → 预览发布 → 人工验收）
- Alice MCP / Claude Code / Codex CLI 三路 Agent 接入
- 统一 Agent 路由协议（任务信封、结构化回执、幂等键）
- 本地备份/恢复（含保护快照）
- 总管工作流状态机（任务信封、阶段回执、交接记录、待验收、失败阻塞、上游返工）
- 32 项自动化测试通过

### v1.1 组织管理

**主题**：让用户能在 Nomos 中建模自己的组织。

**范围**：

- Skill 池 CRUD：创建、编辑、删除、分类管理企业技能资产
- 岗位模板：定义岗位的 Skill 组合、职责描述、验收标准和流程位置
- 员工管理：碳基/硅基/混编员工登记，绑定岗位和底层 Agent
- 岗位-流程矩阵：每个岗位在哪些流程的哪些阶段承担什么角色
- 首页"组织"区独立页面：左侧组织建模、右侧数字员工生成工厂

**不做清单**：

- 不做人员考勤、薪资计算
- 不做组织架构图可视化
- 不做岗位能力自动评估
- 不做跨企业组织共享

**验收标准**：

- 用户能完成一个 5 岗位 / 20 Skill 的 OPC 组织建模
- 每个岗位能关联至少一个流程阶段的角色
- 数字员工六步生成流程的前三步（岗位匹配、入职培训、师父带教）可用

**预估周期**：4-6 周

### v1.2 流程管理

**主题**：让用户能在 Nomos 中定义和管理业务流程。

**范围**：

- 流程库：创建、编辑、删除流程模板，支持价值流/使能流/支撑流三级分类
- 流程模板：定义流程的阶段序列、关口节点、角色责任和输入输出
- 项目绑定流程：创建项目时选择流程模板，项目实例化流程
- 关口评审机制：每个关口有准入条件和准出标准
- 首页"流程"区独立页面：流程库浏览、项目实例追踪

**不做清单**：

- 不做 L2-L5 五级完整分层（留到 v2.0）
- 不做碳硅节点标注（留到 v2.0）
- 不做跨流程编排
- 不做流程仿真和瓶颈分析

**验收标准**：

- 用户能创建一条完整的"LTC 轻量版"流程模板（4-6 个阶段）
- 项目能绑定流程模板，项目阶段与流程阶段关联
- 至少有一个关口评审的准入准出校验生效

**预估周期**：4-6 周

## v2.x 协同引擎阶段

**目标**：让碳硅协同从概念变成可运行的调度引擎。

### v2.0 Workflow 引擎升级

**主题**：从固定五阶段到可配置的多级工作流。

**范围**：

- L2-L5 五级分层：价值流 → 阶段 → 任务 → 步骤 → 节点
- 碳硅节点标注：每个节点明确碳/硅/碳硅属性
- 事件驱动：市场信号、客户行为、数据异常、时间触发启动或推进工作流
- 动态编排：阶段可跳转、可并行、可条件分支
- 流程实例状态追踪：实时显示当前运行到哪个阶段/任务/节点

**不做清单**：

- 不做 SLA 自动计时和超时升级（留到 v2.1）
- 不做跨流程编排
- 不做流程版本管理

**验收标准**：

- 一个 4 阶段 / 12 节点的工作流能完整运行并正确标注碳硅属性
- 硅节点能自动派发给 Agent 执行并回收结果
- 关口节点能根据准入条件自动判断是否放行

**预估周期**：6-8 周

### v2.1 数字员工六步生成

**主题**：完成数字员工从"概念"到"上岗"的完整装配流程。

**范围**：

- 岗位匹配（v1.1 已有基础，增强为智能推荐）
- 入职培训：绑定知识库、业务语料、行业规则
- 师父带教：SOP 沉淀、示范样例
- 分配工具：关联 Agent/Adapter、API、数据源
- 上手实习：沙盒任务、受控权限、人工复核
- 转正上岗：性格定制、协作风格、风险边界、升级机制
- SLA 监控与超时升级：Agent 执行超时自动唤醒人类

**不做清单**：

- 不做 Agent 自动训练和微调
- 不做数字员工的自然语言自主交互

**验收标准**：

- 一个销售助理岗位的数字员工能走完六步生成全流程
- 上岗后的数字员工能在硅节点自动执行并正确回执
- 超时未回执时能正确触发升级

**预估周期**：6-8 周

## v3.x 生态与智能阶段

**目标**：从单机工具变成团队协作平台。

### v3.0 云端同步与团队协作

**主题**：多人、多设备协同运行。

**范围**：

- 账号体系与登录
- 数据云端同步（项目、流程、组织配置）
- 团队工作空间
- 角色-成员映射（流程中的角色绑定到具体团队成员）
- 冲突解决与变更历史

**不做清单**：

- 不做移动端 App
- 不做开放 API 和第三方集成市场

### v3.1 组织诊断与智能推荐

**主题**：让 Nomos 能主动发现组织问题并提供建议。

**范围**：

- 组织健康度仪表盘
- 岗位缺口自动检测
- Skill 缺口推荐
- 流程瓶颈识别
- "症状→流程"反向导航（客户描述问题，系统推荐 Workflow 和 Skill）

## 版本间的依赖关系

```
v1.1 组织管理 ──→ v1.2 流程管理 ──→ v2.0 Workflow 引擎 ──→ v2.1 数字员工 ──→ v3.x
  (组织是流程的     (流程是引擎的      (引擎是数字员工      (员工是团队协作的
   执行基础)         运行基础)          的调度基础)           协作单元)
```

每个版本都必须是**可独立发布、可独立使用**的增量。不做"必须两个版本一起上"的捆绑发布。

---

## 持续进行的跨版本工作

以下工作不绑定到单一版本，持续迭代：

- 安全加固：文件写入权限、命令执行沙盒、数据加密
- Agent 生态扩展：更多 Agent 接入（OpenClaw 启用、云端智能体）
- 性能优化：大数据量下的响应速度
- 文档完善：操作说明书、API 文档、最佳实践
- 自动化测试覆盖率提升
