## 三、Nomos 设计启示：需求翻译层

### 3.1 客户不会说"我要上 LTC"

客户说的是：
- "销售丢单多" → LTC 机会点管理
- "回款慢" → LTC 回款管理
- "客户跟丢了" → MCR 客户接触管理
- "新人不会干" → MHR 培训 + 组织记忆继承
- "不知道卖多少钱" → IPMS 定价策略 + LTC 报价审批

**Nomos 的界面设计应该支持"症状→流程"的反向导航**：客户描述问题，系统自动推荐对应的 Workflow 和 Skill。

### 3.2 一个需求常跨多个 L1 流程

比如"发 AI 工具"这个需求，表面是 IT 的事，实际涉及：
- BT&IT：工具选型、账号开通
- MF/IFS：成本预算、费用分摊
- MQ：数据安全、合规审计
- MHR：使用培训、能力评估

**Nomos 的 Workflow 设计需要支持跨 L1 流程编排**：一个"AI 工具落地 Workflow"可以自动串联 BT&IT、MF、MQ、MHR 的相关子流程。

### 3.3 L4 是碳硅协同的最小单元

L4 四级操作是 Nomos 中碳硅节点调度的最小粒度。每个 L4 操作需要明确：
- **操作类型**：碳（人执行）/ 硅（Agent 执行）/ 碳硅（Agent 辅助 + 人决策）
- **输入**：需要什么数据/材料
- **输出**：产生什么交付物
- **工具**：需要调用什么 Skill 或外部系统
- **时限**：SLA 要求

**示例**：LTC 的 L4 操作"决策链地图绘制"
- 类型：碳硅混合（Agent 从 CRM/工商数据自动抓取组织架构，销售补充关键人关系和影响力评估）
- 输入：客户公司名称、已有联系人、公开招投标信息
- 输出：决策链地图（组织结构 + 关键人角色 + 关系亲疏 + 影响力评分）
- 工具：客户画像 Skill + 工商数据 API + 关系图谱分析
- 时限：商机立项后 3 个工作日内完成

## 四、待补充的 L4 深度拆解

本文档已建立"需求→L1→L2→L3→L4"的完整映射框架。以下流程的 L4 操作细节仍需进一步细化：

| 流程 | 状态 | 说明 |
|------|------|------|
| LTC | L4 框架已建立 | 需补充每个 L4 操作的碳硅属性标注 |
| MCR | L4 框架已建立 | 需补充客户档案、拜访管理的 L4 操作细节 |
| IPD | L3 较完整 | 需将 TR/DCP 评审拆解为 L4 检查清单 |
| IPMS | L3 较完整 | 需补充 GTM 各阶段的 L4 操作 |
| MHR | L4 框架已建立 | 培训、绩效、激励的 L4 需结合 AI 场景细化 |
| BT&IT | L4 框架已建立 | 需补充 AI 工具特有的 L4 操作（如 Prompt 审计） |
| ITR | L3 较完整 | 需补充一线快速解决的 L4 自动化工单处理 |
| Supply/ISC | L3 较完整 | 需补充需求预测和交付承诺的 L4 算法细节 |
| DSTE | L3 较完整 | 需补充战略解码到个人目标的 L4 分解操作 |
| CRS/SD/MCI/MBS/MQ | L2-L3 有框架 | 公开资料有限，部分 L4 需基于行业通用模式推演 |
