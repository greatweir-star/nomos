# Nomos 项目管理中心

这里是 Nomos 从 v0.0.3 起的研发管理唯一入口。现有文件暂不移动，避免历史链接和发布脚本失效；通过资料台账把所有材料归类为“项目级”或“版本级”。

## 两级资料体系

| 层级 | 用途 | 目录 |
| --- | --- | --- |
| 项目级资料 | 长期有效的产品方向、治理规则、研发流程、术语和配置管理 | `项目级资料/` |
| 版本级资料 | 某个版本的需求、架构、设计、任务、测试、验收和交接材料 | `版本级资料/Vx.y.z/` |

## 文档优先级

发生冲突时，按以下顺序处理：

1. 已批准的版本决策与 ADR。
2. 当前版本 PRD 与验收矩阵。
3. 当前版本架构、前后端和测试设计。
4. 项目级规范。
5. 历史版本、旧规划和研究资料。

任何智能体不得用历史文档覆盖当前版本决策；发现冲突应提交给产品经理/架构师处理。
