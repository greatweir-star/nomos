## 正式发布前剩余门槛

1. 使用 Apple Developer ID Application 证书重签 macOS 应用并提交 Apple 公证，重新生成 SHA256。
2. 在实际安装了 Alice、Kimi 的环境补充连接发现和可管理性检查；若不纳入首发支持，则在官网明确标记为“实验性/未验证”。

本次对外发布平台仅为 macOS Apple Silicon，Windows 不进入 V0.0.3 发布门禁。

以上门槛未完成前，制品只可用于内部/受控候选测试，不应作为面向公众的正式稳定版宣传。
