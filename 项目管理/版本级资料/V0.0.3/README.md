# Nomos V0.0.3 版本交付包

> 版本状态：Sprint 1–6 完成，macOS 内部候选发布通过；等待签名与 Apple 公证  
> 规划日期：2026-06-21  
> 计划周期：2026-06-22 至 2026-09-13（6 个双周迭代）  
> 核心需求源：[`NOMOS-PRD.md`](../../../产品开发/nomos-desktop/docs/NOMOS-PRD.md)

## 1. 版本主题

**把现有 Agent/项目演示产品收敛为以流程为核心、按岗位调度碳硅员工、具备真实派发—回执—验收闭环的本地管理系统。**

## 2. 版本目标

1. 完成一级信息架构和真实数据原则归位。
2. 分离 AdapterTemplate、ConnectionProfile 与 Employee。
3. 支持同一技术连接实例化多个会话隔离的硅基员工。
4. 建立 Skill、Position、Employee 和管理权限模型。
5. 建立可发布流程版本、项目快照和工作项生成。
6. 跑通按岗位路由、确认派发、执行、回执、验收和返工。
7. 完成旧数据迁移、备份恢复、安全和发布质量门禁。

## 3. 版本范围

纳入核心 PRD Phase 0–4，并增加发布加固阶段；Phase 5“远程执行与多人协作”不进入本版。

## 5. 启动顺序

1. 架构师确认 ADR 与 API v1 合同。
2. 后端建立领域骨架、数据库迁移和 mock/contract server。
3. 前端基于冻结合同和 mock 数据并行实现。
4. 测试同步建立合同测试与核心 E2E，不等待功能全部完成。
5. 每个迭代末完成纵向闭环演示，不以“模块代码写完”代替可用结果。
