# Nomos V0.0.3 M6 联合验收记录

> 日期：2026-06-21  
> 范围：控制台、迁移、备份恢复、安全、诊断、桌面打包  
> 结论：功能与静态发布门禁通过；进入候选发布制品验证

## 完成内容

- 控制台全部使用真实数据库统计和异常项，不展示固定告警或虚构负载。
- 增加 SQLite 备份、完整性检查、显式确认恢复、恢复前保护备份和失败回滚。
- 增加旧 v9 数据 dry-run、敏感字段报告、确认迁移和来源哈希幂等控制；源文件不被修改。
- 会话密钥仅在内存物化，数据库不保存原值；增加敏感信息扫描、审计查询和安全响应头。
- 应用异常中断后，将执行、派发、容量租约和工作项恢复为可解释状态。
- 新版 Renderer 成为桌面端默认入口，旧版保留为显式兼容入口。
- 建立 macOS Apple Silicon 与 Windows x64 发布构建配置和自动发布检查。
