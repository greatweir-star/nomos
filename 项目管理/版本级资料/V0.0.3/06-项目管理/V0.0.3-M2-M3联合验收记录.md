## M3：组织可实例化

- Skill 支持创建、编辑、停用和引用保护；被岗位引用时返回 `409 REFERENCE_CONFLICT`。
- Position 完整保存职责、验收标准、Skill 和管理权限边界。
- Employee 支持草稿、提示词快照/独立会话物化、入职检查、暂停、恢复和离职状态机。
- 同一 ConnectionProfile 可创建多个硅基员工，sessionKey 与 promptSnapshot 独立；API 只返回脱敏会话标识。
- PermissionRequest 支持申请、Owner 审批、拒绝、撤销和到期失效。
- 真实浏览器完成“创建 Skill → 创建岗位 → 创建数字员工 → 入职检查”，员工最终进入 `schedulable`。
