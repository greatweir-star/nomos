> 日期：2026-06-21

## 完成内容

- 统一产品版本为 `0.0.3`。
- 增加 TypeScript 后端构建、前端生产构建、统一类型检查和新旧测试脚本。
- `npm test` 现在同时覆盖旧系统测试与 V0.0.3 分层测试。
- Node 22 测试环境使用 `--experimental-sqlite` 启动新数据库测试。
- V0.0.3 本地服务能够同源提供 React Renderer 与 `/api/v1`。
- 新增真实空数据 Dashboard API，控制台不依赖生产 Mock。
- Electron 保留旧入口；`--renderer-v2` 或 `NOMOS_RENDERER=v2` 可选择新入口。
- 打包文件范围包含 `dist-ts` 和 `renderer-v2`，生成目录不进入版本控制。
- React 控制台内部跳转改为 Router Link，避免整页导航。

- Browser 截图接口超时，但 DOM、路由、API、静态资源和控制台日志证据均已取得。
- Sprint 1 页面除控制台外仍是规划空态，后续功能按 FE/BE 任务包推进。
