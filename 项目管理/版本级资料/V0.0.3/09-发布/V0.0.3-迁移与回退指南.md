# Nomos V0.0.3 迁移与回退指南

## 从旧版迁移

1. 启动 V0.0.3，进入“设置 → 数据迁移”。
2. 选择检测到的旧 v9 数据，先执行 dry-run。
3. 检查可导入数量、歧义项和敏感字段报告；系统不会修改源文件。
4. 迁移前在“备份恢复”创建一次备份，再显式确认导入。
5. 导入完成后核对 Skill、岗位、碳基员工和系统诊断。

旧版硅基/混合员工、项目、流程和工作项因模型语义不明确，不自动导入；报告会列出跳过数量。敏感凭据和会话字段永不迁移。

## 备份与恢复

1. 在“设置 → 备份恢复”创建备份并确认完整性为 `ok`。
2. 恢复前先检查备份详情；存在运行中执行时系统会阻止恢复。
3. 输入显式确认后恢复。系统会自动创建恢复前保护备份；失败时回滚。
4. 恢复后重新运行系统诊断并核对对象数量。

## 应用版本回退

退出 Nomos，保留当前数据库备份，安装上一版本并恢复由该版本创建的兼容备份。V0.0.3 数据库迁移不提供向下改写；不要用旧程序直接打开已升级数据库。
