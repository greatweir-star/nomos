# Nomos V0.0.3 发布说明

V0.0.3 将 Nomos 收敛为以流程为核心的本地数字员工项目指挥台，完成从技术连接、岗位与员工，到流程项目、派发回执、人工验收的可追溯闭环。

## 主要更新

- 新增七个一级工作区：控制台、组织、能力池、流程、派发、项目、设置。
- 同一技术连接可实例化多个岗位员工，并保持提示词、会话和回执隔离。
- 流程发布后不可变；项目启动时保存流程快照并生成岗位责任工作项。
- 派发增加资格过滤、排序解释、幂等确认、容量控制和中断恢复。
- Receipt 只陈述执行结果，Acceptance 独立决定通过或返工。
- 新增 SQLite 备份恢复、旧数据迁移预检、系统诊断、审计与敏感信息扫描。

## 安装与首次使用

- macOS Apple Silicon：打开 DMG，拖入“应用程序”；未签名候选包仅用于内部验收。
- Windows x64：解压 ZIP 后运行 `Nomos.exe`，请保持解压目录结构完整。
- 首次启动后先进入“设置 → 技术连接”检测并保存连接，再创建岗位、员工、流程与项目。

## 已知限制

- V0.0.3 是本地单用户版本，不包含远程执行、多用户协作和云同步。
- Nomos 管理派发与回执证据，不接管智能体的目录、命令、网络权限或沙箱。
- Alice、Kimi 因当前验收环境未安装，发布前需在对应环境补充连接实测。
- 当前 macOS 候选包未进行 Apple Developer ID 签名和公证，不作为正式公网分发包。
