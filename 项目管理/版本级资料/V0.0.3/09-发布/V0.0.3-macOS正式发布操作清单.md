# Nomos V0.0.3 macOS 正式发布操作清单

## 当前已完成

- 本地 Apple Silicon DMG/ZIP 构建、临时签名、严格签名结构校验和真实启动健康检查。
- Node 22/24 下 92 项自动化测试及生产构建通过。
- GitHub macOS 托管运行器完成干净安装、测试、打包、签名结构校验和候选制品上传。
- 发布分支：`codex/v0.0.3-release`。

## 一次性凭据配置

在 GitHub Actions Secrets 中配置：

- `MAC_CSC_LINK`：Developer ID Application 证书的加密 P12 内容或可下载地址。
- `MAC_CSC_KEY_PASSWORD`：P12 密码。
- `APPLE_ID`：用于公证的 Apple ID。
- `APPLE_APP_SPECIFIC_PASSWORD`：Apple 专用密码。
- `APPLE_TEAM_ID`：Apple Developer Team ID。

凭据只进入 GitHub Secret，不写入仓库、日志、配置文件或发布材料。

## 正式发布

1. 合并 `codex/v0.0.3-release` 到默认分支。
2. 创建并推送标签 `v0.0.3`。
3. `Release Nomos Desktop` 流水线自动执行完整门禁、Developer ID 签名、Apple 公证、Gatekeeper 与 stapler 校验。
4. 流水线为 DMG/ZIP 生成新的 SHA256，并创建 GitHub Release。
5. 下载正式制品，在一台未安装过 Nomos 的 Apple Silicon Mac 上完成首次安装、启动、备份恢复和退出重启冒烟测试。

任何凭据缺失、签名失败、公证失败、Gatekeeper 拒绝或测试失败都会阻止 Release 创建。
