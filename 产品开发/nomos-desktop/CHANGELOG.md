# Changelog

## [1.2.0] - 2026-06-07

### Added

- **流程模板库**：支持创建、编辑、删除、复制流程模板，按价值流 / 使能流 / 支撑流三级分类，支持搜索和筛选。（路径：流程 > 流程库）
- **流程模板编辑器**：可视化编辑阶段序列，配置关口评审（准入条件 / 准出标准），每个阶段可定义角色责任和输入输出。（路径：流程库 > 编辑模板）
- **流程实例运行**：项目绑定流程模板后，按模板阶段序列运行，支持阶段推进、关口评审、退回返工。（路径：项目详情 > 流程阶段）
- **流程实例追踪**：独立追踪面板，展示所有运行中的流程实例，阶段时间线可视化。（路径：流程 > 实例追踪）
- **默认模板**：内置 "LTC 轻量版"（线索管理 → 商机评估 → 方案设计 → 合同签订）和 "项目交付"（需求定义 → 方案设计 → 开发实施 → 验收交付）。（路径：流程库 > 使用预设模板）
- **项目绑定流程**：创建项目时可选流程模板，自动实例化流程阶段序列。（路径：新建项目 > 选择流程模板）
- **关口评审**：支持碳评审（人工）、硅评审（Agent）、碳硅评审（Agent 预审 + 人工终审）三种评审方式，评审结果支持通过 / 不通过 / 需返工。

### Changed

- 数据版本从 v7 升级到 v8，向后兼容。
- 后端新增 `flow-api.js` 模块（约 400 行），集中处理流程相关 API。
- `server.js` 新增 18 个 API 路由，覆盖流程模板 CRUD、流程实例生命周期和关口评审。
- `app.js` 新增约 500 行前端代码，覆盖流程库浏览、模板编辑器、实例追踪和评审面板。
- 项目数据模型扩展 `flowTemplateId` 和 `flowStages` 字段，未绑定模板的项目行为不变。

### Fixed

- 无。

## [1.1.0] - 2026-06-05

### Added

- 组织管理页面：概览、Skill 池、岗位、员工、数字员工工厂五个子页。
- Skill 池 CRUD：支持名称唯一性、分类、等级、来源、标签、适用流程、风险边界和能力证据字段。
- 岗位 CRUD：支持岗位族、碳/硅/混编类型、职责、Skill 组合、验收标准和流程关联说明。
- 员工 CRUD：支持碳基、硅基、混编员工，硅基员工引用现有本地 Agent。
- Adapter 视图：从现有 `agents` 和 `agentAdapters` 聚合展示技术架构身份。
- 组织健康度：统计 Skill、岗位、员工、Agent 覆盖率、空岗位族、无员工岗位和无 Skill 岗位。
- 默认模板：通过 `POST /api/org/init-defaults` 按需生成 7 大岗位族、21 个 Skill 和 8 个岗位。
- 数字员工工厂前三步：岗位匹配、入职培训、师父带教，支持草稿保存、恢复和状态机校验。

### Changed

- 数据版本从 v6 升级到 v7，自动补全 `skills`、`roles`、`employees`。

## [1.0.1] - 2026-06-03

### Added

- Windows x64 便携客户端首次发布。
- 本机 HTTP 后端和 JSON 持久化，无需额外数据库。
- 项目创建、编辑、删除、搜索和五阶段交付链路。
- Alice MCP、Claude Code、Codex CLI、本地执行预览、二次确认、取消、重试和回执。
- 本地备份、恢复预览、恢复前保护快照和活动任务恢复拦截。
