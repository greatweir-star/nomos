# V1 核心路径测试用例

> 本文档定义 Nomos v1.0.1 必须通过的手工验收路径。每个版本发布前必须逐条执行。

## 测试环境

- Windows x64 系统
- 已安装 Alice CLI（可选）、Claude Code CLI（可选）、Codex CLI（可选）
- 无需网络连接（本地优先）

---

## TC-01：首次启动

**目标**：验证新用户首次安装后的引导体验。

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 首次启动 Nomos 便携版 | 显示引导页，不显示演示数据 |
| 2 | 观察引导页内容 | 包含"创建项目"和"检查本地 Agent"两个入口 |
| 3 | 关闭客户端后重新打开 | 不再显示引导页，进入空工作区 |

**通过标准**：首次启动到进入空工作区的完整流程无报错。

---

## TC-02：创建项目

**目标**：验证项目 CRUD 全流程。

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 点击"创建项目" | 弹出创建项目弹窗 |
| 2 | 填写项目名称"测试项目A"，保存 | 项目出现在列表中，名称正确 |
| 3 | 点击项目进入详情 | 显示项目总览、五阶段链路 |
| 4 | 编辑项目设置，修改名称为"测试项目B" | 名称更新成功 |
| 5 | 返回列表，搜索"项目B" | 能搜到该项目 |
| 6 | 删除该项目 | 项目从列表中消失 |

**通过标准**：创建、编辑、搜索、删除全流程无报错。

---

## TC-03：阶段链路与工作流

**目标**：验证五阶段交付链路和状态机。

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 创建项目"工作流测试" | 项目显示五阶段链路 |
| 2 | 观察初始状态 | 当前阶段为"提出目标" |
| 3 | 在"提出目标"阶段提交目标描述 | 目标描述显示在阶段详情中 |
| 4 | 点击"推进" | 工作流推进到下一阶段（总管拆解） |
| 5 | 观察各阶段状态 | 已完成阶段标记完成，当前阶段高亮 |
| 6 | 到达"人工验收"阶段 | 显示验收操作入口 |

**通过标准**：阶段链路完整显示，状态流转正确。

---

## TC-04：Agent 检测

**目标**：验证本地 Agent 检测功能。

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 进入"本地 Agent"页面 | 显示 Agent 列表 |
| 2 | 观察检测状态 | Alice、Claude Code、Codex CLI 各显示检测状态（已安装/未安装） |
| 3 | 如果 Claude Code 已安装 | 状态显示为可用 |
| 4 | 如果 OpenClaw 未配置 | 状态显示为待配置，不自动启动 |

**通过标准**：Agent 检测状态正确反映本机实际情况。

---

## TC-05：本地任务派发

**目标**：验证受控本地执行的全流程。

**前置条件**：至少一个 CLI Agent（Claude Code 或 Codex CLI）可用。

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 在项目详情中点击"派发任务" | 弹出任务配置弹窗 |
| 2 | 选择"只读分析"，输入工作目录和任务说明 | 命令预览正确生成 |
| 3 | 确认执行 | 任务开始执行，显示实时输出 |
| 4 | 等待执行完成 | 显示执行结果，工作流推进 |
| 5 | 创建新任务，选择"代码写入" | 系统提示写入风险 |
| 6 | 确认执行 | 二次确认弹窗出现 |
| 7 | 确认写入 | 任务开始执行 |

**通过标准**：只读和写入两种模式的执行、确认、回执全流程正确。

---

## TC-06：备份恢复

**目标**：验证本地备份和恢复功能。

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 创建至少一个项目 | 项目存在 |
| 2 | 进入备份功能，执行备份 | 备份成功，显示备份文件列表 |
| 3 | 删除刚才创建的项目 | 项目被删除 |
| 4 | 选择刚才的备份文件，执行恢复预览 | 显示将要恢复的数据 |
| 5 | 确认恢复 | 系统创建保护快照，恢复数据 |
| 6 | 确认项目已恢复 | 被删除的项目重新出现 |
| 7 | 检查保护快照 | 存在 pre-restore 快照 |

**通过标准**：备份、删除、恢复全流程无数据丢失。

---

## TC-07：Alice MCP 派发

**目标**：验证 Alice MCP 任务派发和回执同步。

**前置条件**：Alice CLI 已安装且 MCP 服务可用。

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 在项目某阶段点击"Alice 派发" | 显示任务派发预览 |
| 2 | 确认派发 | 任务发送到 Alice MCP，显示已派发状态 |
| 3 | Alice 完成任务后，同步回执 | 回执内容显示在阶段详情中 |
| 4 | 再次派发同一任务 | 系统拦截，提示同轮已派发 |

**通过标准**：Alice 派发、回执同步、幂等拦截全流程正确。
