# Nomos 项目目录

Nomos 是面向中小企业和 OPC 的流程驱动型智能操作系统。本目录按产品生命周期整理，避免产品资料、开发过程、正式发布和参考源码混在一起。

> 从 V0.0.3 起，项目治理、版本基线、研发任务和验收材料统一从 [`项目管理/README.md`](项目管理/README.md) 进入。历史资料保留原位，通过资料台账分类管理。

## 目录结构

```text
nomos
├─ 产品规划
│  ├─ 00-产品理念
│  ├─ 01-调研资料
│  ├─ 02-PRD
│  ├─ 03-版本规划
│  ├─ 04-详细规划
│  └─ 05-商业化规划
├─ 产品开发
│  ├─ nomos-desktop
│  ├─ 测试用例
│  ├─ 测试报告
│  └─ 中间数据
├─ 产品发布
│  ├─ v1.3.0
│  ├─ V0.0.3
│  ├─ v1.2.0
│  ├─ v1.1.0
│  ├─ v1.0.1
│  ├─ GitHub源码
│  └─ 发布说明
└─ 参考源码
```

## 使用规则

- `产品规划`：存放产品层面的调研、理念、PRD、版本规划、详细设计、商业化规划和需求映射。
- `产品开发`：存放开发中的源码、测试用例、测试报告和临时过程数据。当前桌面客户端源码在 `产品开发\nomos-desktop`。
- `产品发布`：存放正式发布产物、源码归档、GitHub 发布材料和版本说明。
- `参考源码`：存放可学习、可复用的外部源码。接到新的开发任务时，应优先阅读这里的相关项目，再决定实现方案。

## 当前开发入口

```shell
cd 产品开发/nomos-desktop
npm run release:check
npm run dist:win
```

V0.0.3 候选制品和发布材料已归档到 `产品发布/V0.0.3`。正式公网版本仍须通过 Windows 实机回归和 macOS Developer ID 签名、公证门禁。
